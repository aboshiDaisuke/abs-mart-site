Snapfold

写真のサムネイルを見ながら並べ替えて、連番でまとめてリネーム。フォルダ分けまで一気にできる Mac アプリ。

FEATURESできること

ドラッグで並べ替え

サムネイルを見ながら、写真をつかんで好きな順番に。

連番で名前をつける

並べた順のまま、まとめて連番のファイル名に。

フォルダにまとめる

名前を付けた写真を、そのままフォルダに整理。

INSTALLインストール方法

  1. 「ターミナル」を開く

    command + スペース を押して「ターミナル」と入力し、return を押します。

  2. 下の1行をコピーして、ターミナルに貼り付けて return
    curl -fsSL https://apps.abs-mart.net/install.sh | bash -s snapfold
  3. 1分ほど待つと Snapfold が起動

    アプリは「アプリケーション」フォルダに入ります。

NOTES知っておくと安心

更新するとき

新しい版が出たら、同じ1行をもう一度実行するだけ。設定はそのまま残ります。

パスワードを聞かれたら

Mac にログインするときのパスワードを入れて return。入力中は文字が表示されませんが、そのままで大丈夫です。

対応する Mac

M1 以降の Mac（Apple シリコン）。Intel の Mac には対応していません。

アンインストール

「アプリケーション」フォルダの Snapfold をゴミ箱に入れるだけです。
